# markdown-to-html

This project converts Markdown text to HTML using Swift and now includes a simple interactive command-line UI.

## Usage

1. Build and run the executable:
   ```bash
   swift run
   ```
2. Type or paste your Markdown content into the prompt.
3. Enter `END` on a new line when you are finished.
4. The tool will generate an HTML file in your temporary directory and attempt to open it automatically with your default browser.

If automatic opening is not available on your system, the tool will display the path to the generated HTML file so you can open it manually.
